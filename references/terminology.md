# Bolt terminology

Rules marked (**must**) are non-negotiable. Everything else is the default (should).

## Use this

| Term | Casing | Context |
|---|---|---|
| Bolt.new, then Bolt | as shown | "Bolt.new" on first mention in a piece, "Bolt" after that |
| project | lowercase | What someone builds, in product UI ("Create project") |
| site | lowercase | What someone builds, when the subject is publishing, domains, or visibility ("Published site visibility") |
| apps and websites | lowercase | What people build, in marketing and onboarding |
| agent | lowercase | The AI in Bolt. In chat it says "I" |
| publish | lowercase | Putting a site or project live. Never "deploy" |
| token | lowercase | The unit of usage |
| refill | lowercase | Never "Refill" |
| team | lowercase | The shared space members belong to |
| personal account | lowercase | Someone's own space outside any team |
| sign in, sign up | sentence case in UI | Authentication |
| turn on, turn off | keep verb and "on/off" together | Settings: "turn on notifications," not "turn notifications on" |
| select, choose | lowercase | Navigation. "Select" for interface elements, "choose" for decisions. "Tap" only in mobile-specific steps |
| text message | lowercase | "Text" when space is tight |

In chat, the agent names what the person is building in their own terms ("I added a contact form to your site").

## Never this

| Don't say | Say instead | Enforcement |
|---|---|---|
| deploy | publish | (**must**) |
| credit | token | should |
| workspace, organization (for the shared space) | team, or personal account | should |
| model, LLM, AI engine | agent | should |
| log in, register | sign in, sign up | should |
| enable, disable, activate, deactivate | turn on, turn off | should |
| external users | people outside your team | should |
| enforce, per-project, user-specified | plain words for what happens | should |
| SMS | text message | should |
| click here, learn more | link text that names where it goes | should |
| blacklist, whitelist, master | blocklist, allowlist, main | should |

## Exact wording

Text in this section is reproduced byte-for-byte, never paraphrased or reformatted (see AGENTS.md).

> \*Plus tax

**Scope:** every price Bolt shows, in every channel and locale (pricing page, upgrade screens, emails, ads). Put an asterisk directly after the price ("$25/month\*") and place the note below it, starting with the asterisk. **Owner and source:** this repository is the official source. No separate legal owner has been named; changes need approval from this repository's approver. Shared wording never overrides local tax or consumer-law requirements. If a market requires different wording (for example, prices that must include VAT), stop and ask.
